
## 1. Product Overview
天津市市政公路管理局官方网站，提供单位介绍、领导班子、直属单位、主要职责等信息展示。
- 主要面向公众和内部人员，展示市政公路管理局的基本情况和工作动态
- 提升政务公开透明度，为社会提供便捷的信息查询服务
- 设计风格遵循政务网站规范：稳重、正式、专业，注重信息架构清晰

## 2. Core Features

### 2.1 Feature Module
1. **首页**: 顶部导航、横幅轮播、单位简介、领导介绍、直属单位、主要职责、政务动态
2. **关于我们**: 单位历史沿革、详细职责介绍、指导思想
3. **领导班子**: 领导成员详细信息展示
4. **直属单位**: 各直属单位信息展示

## 4. User Interface Design
### 4.1 Design Style
- **主色调**: 红色 (#dc2626)、深蓝色 (#1e40af)、白色 (#ffffff)
- **辅助色**: 浅蓝色 (#3b82f6)、浅灰色 (#f3f4f6)
- **按钮风格**: 圆角矩形，有悬停效果，稳重正式
- **字体**: 思源黑体，标题加粗，清晰易读
- **布局风格**: 版心式布局，顶部导航 + 分区布局，卡片式设计
- **图标风格**: 简洁的线性图标
- **配图风格**: 实景配图，传递真实感和信任感

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 首页 | 顶部导航 | 固定在顶部，白色背景，红色或深蓝色文字，悬停变色 |
| 首页 | 横幅轮播 | 全屏宽度，实景配图，自动轮播，带指示器 |
| 首页 | 单位简介 | 白色卡片，浅灰色背景，左右布局，实景配图 |
| 首页 | 领导介绍 | 卡片式，头像+姓名+职务 |
| 首页 | 直属单位 | 网格布局，白色卡片，蓝色边框 |
| 首页 | 主要职责 | 列表式，带图标，清晰的层级 |
| 首页 | 指导思想 | 突出展示，红色或深蓝色强调 |
| 领导班子 | 领导列表 | 响应式网格，卡片悬停效果 |

### 4.3 Responsiveness
- Desktop-first 设计，适配平板和移动设备
- 移动端导航转为汉堡菜单
- 网格布局在小屏幕自动调整为单列
